## 文件说明

### 1. 声韵网页端.html（主页面）
- 完整的Web应用页面
- 双击即可在浏览器中打开
- 无需安装任何依赖

**使用方法：**
1. 直接双击 `声韵网页端.html` 在浏览器中打开
2. 或使用 `python -m http.server 8000` 启动本地服务器
3. 浏览器访问 `http://localhost:8000`

**功能说明：**
- 四个快捷功能按钮：气息问题诊断、曲目风格解析、课前热身方案、演唱技巧速查
- 自由输入框：可输入任何声乐相关问题
- 流式响应：AI回复以打字机效果显示
- 对话历史：自动维护最近40条对话上下文

## 复现指南

如需复现本项目，请按以下步骤操作：

### 步骤1：注册腾讯元器
1. 访问 https://yuanqi.tencent.com
2. 注册并登录账号
3. 创建新智能体

### 步骤2：配置智能体
1. 设置角色设定（参考开发日志中的提示词）
2. 上传知识库文档
3. 配置开场白和快捷问题

### 步骤3：获取API密钥
1. 在智能体设置中获取 AppID 和 AppKey
2. 更新 index.html 中的配置

### 步骤4：运行测试
1. 双击打开 index.html
2. 在浏览器控制台查看 API 调用日志
3. 如遇 CORS 问题，考虑使用代理服务器
