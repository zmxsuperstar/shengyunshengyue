# 「声韵」声乐AI教学助手 使用手册

## 产品简介

「声韵」是一款基于人工智能技术的声乐教学辅助工具，由大连艺术学院戏剧影视与传媒学院表演基础教研室开发。

它可以为声乐学习者提供专业、便捷的智能辅导服务，帮助解决学习和演唱中的各类问题。

## 快速开始

### 启动方式

1. **方式一**：直接双击 `声韵网页端.html` 文件，在浏览器中打开
2. **方式二**：启动本地服务器
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 然后在浏览器访问
   # http://localhost:8000
   ```

## 功能详解

### 1. 气息问题诊断

帮助分析和解决气息相关的问题，包括：
- 气浅、气短
- 气息僵硬、流动性差
- 气息支持不足

**使用示例：**
> "我唱歌时气息总是不够用，两句就没气了"

### 2. 曲目风格解析

针对不同风格的声乐作品，提供演唱处理建议，包括：
- 中国艺术歌曲
- 外国歌剧咏叹调
- 民族歌曲
- 音乐剧唱段

**使用示例：**
> "《玫瑰三愿》应该怎么处理？"

### 3. 课前热身方案

提供标准化的声乐热身流程，包括：
- 身体放松运动
- 呼吸觉醒训练
- 发声准备练习
- 音阶热身

**使用示例：**
> "给我一个标准的课前热身方案"

### 4. 演唱技巧速查

快速解答声乐技巧问题，包括：
- 高音技巧
- 换声处理
- 共鸣调节
- 咬字吐字

**使用示例：**
> "高音上不去怎么办？"

### 5. 自由提问

除了快捷功能，您还可以自由提问任何声乐相关的问题：

**使用示例：**
- "如何在艺考中展现自己的特色？"
- "怎样练习腹式呼吸？"
- "唱歌时喉位太高怎么解决？"

## 使用技巧

### 获得更好的回答

1. **描述具体问题**：越具体的问题，获得的回答越有针对性
2. **说明背景**：如"我是初学者"或"准备艺考中"
3. **一次一问**：一个问题问清楚后，再问下一个

### 避免的问题

1. **过于笼统的问题**：如"怎么唱歌好听"
2. **超出范围的问题**：本智能体专注于声乐教学，不涉及其他领域

## 注意事项

### AI生成内容标注

根据《生成式人工智能服务管理暂行办法》，本智能体输出的AI生成内容（文本、图片、音频、视频等）均须明确标注"AI生成"。

### 内容局限性

- 本智能体基于知识库训练，可能存在知识盲区
- 不涉及医疗诊断，不提供医疗建议
- 建议结合教师指导使用

### 隐私保护

- 请勿在对话中透露个人隐私信息
- 不出现学生正面画面（如录制视频）
- 保护学生个人信息

## 常见问题

### Q: 为什么有时候回答很慢？
A: 网络状况或服务器负载可能影响响应速度，请耐心等待。

### Q: 回答不准确怎么办？
A: 可以重新表述问题，或提供更多背景信息。

### Q: 如何保存对话记录？
A: 当前版本不自动保存对话，建议截图保存重要内容。

### Q: 支持语音输入吗？
A: 当前版本仅支持文本输入，语音功能开发中。
